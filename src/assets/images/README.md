# Folder Gambar (images)

Taruh logo aplikasi di sini dengan nama file **logo.png**
(dipakai oleh `src/screens/SplashScreen/index.js`).

Rekomendasi ukuran: 512x512 px, background transparan, format PNG.

Jika Anda memakai nama/format file lain, jangan lupa update baris
`require('../../assets/images/logo.png')` di SplashScreen.
